# AI Learning content layout

Store each source as a Markdown file under `<source>/<author>/<file>.md`.
For sources with a subtype, use `<source>/<subtype>/<author>/<file>.md`.

Examples:

- `youtube/<channel>/<video-title>.md`
- `blogs/medium/<author>/<post-title>.md`

Add frontmatter with `source`, `author`, and the source URL when known.
