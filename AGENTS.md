# AI Learning content layout

Store each source as a Markdown file under `<source>/<author>/<file>.md`.
For sources with a subtype, use `<source>/<subtype>/<author>/<file>.md`.

Examples:

- `youtube/<channel>/<video-title>.md`
- `blogs/medium/<author>/<post-title>.md`

Add frontmatter with `source`, `author`, and the source URL when known.

## Change log

Record each valuable project change in the root `LOG.md`, including new or materially updated learning entries.
Do not record routine maintenance or housekeeping, such as README updates or formatting-only changes.
Add a short entry with the date, the change, and its value to the project.
